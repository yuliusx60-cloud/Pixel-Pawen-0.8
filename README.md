# Pixel Pawns – APK

1. ارفع محتويات هذا المجلد كلها إلى مستودع GitHub جديد (فرع main).
2. افتح تبويب **Actions** وانتظر انتهاء "Build APK" (3–6 دقائق). يمكن تشغيله يدويًا من **Run workflow**.
3. افتح تشغيلة العمل المكتملة ونزّل **Pixel-Pawns-APK** من قسم Artifacts، فك الضغط وستجد app-debug.apk.
4. انقل الملف للهاتف وثبّته (فعّل "التثبيت من مصادر غير معروفة").

- أيقونة التطبيق: assets/icon-only.png (وicon-background.png للأيقونة المتكيفة).
- اللعبة نفسها: www/index.html. عدّلها وارفعها فيُبنى APK جديد تلقائيًا.
- ميزة اللعب أونلاين تعمل داخل claude.ai فقط، أما باقي أوضاع اللعب فتعمل بشكل طبيعي.
- خط Press Start 2P يُحمَّل من الإنترنت؛ بدونه يظهر خط بديل.
